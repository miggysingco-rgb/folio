# Folio (offline)

Folio is a notebook app: PDFs with handwriting, notes and small study apps. This repository holds only the app's page, so it can be installed on a phone or tablet and used without internet.

- Open the site in Safari, then Share › Add to Home Screen.
- Everything you add stays on your own device. Nothing personal is stored here.

Files: `index.html` (the app), `sw.js` (keeps the page available offline), `manifest.json` and the icons (for installing).
